# CHANGELOG

## 0.9.0 — 2026-07-30

- 工作流收敛为四个公开节点：`start_input`、`ocr_llm_candidates`、`fill_word`、`output`，每个节点都有独立的输入/输出模型和职责说明。
- LLM 改为先为 Word 固定位置生成全部候选，再由前端人工选择；选择接口只允许提交已生成候选，不允许客户端改写候选文本。
- 移除格式审核、数据校验、语义审核及审核汇总运行节点和产物；缺失内容继续保留并高亮 `XXX`，对外只输出待复核 Word，内部解析轨迹不作为下载产物。

## 0.8.0 — 2026-07-28

- PDF OCR 默认改为阿里云文档智能“文档解析（大模型版）”，本地不再加载 PaddleOCR；保留 SHA-256 缓存优先、显式 `paddle` 模式和 API 失败继续生成待复核 Word 的行为。
- 新增阿里云异步提交、状态轮询、布局分页及页码/坐标/表格单元格转换；AccessKey 不进入日志、运行产物或 Git。
- 前端材料上传收敛为三个业务槽位：审计报告 PDF、资产基础法/资产清查 Excel、收益法或市场法 Excel；移除参考报告 DOCX 和审计财务 Excel 上传项，Word 模板仍由后端固定提供。
- Excel 取数调整为通用语义识别优先，项目固定坐标仅在语义结果缺失时回退；历史表只补空值，不再整体覆盖更可信的语义结果。
- 新增未完成评估识别：账面净资产非零、评估净资产为零且同一评估列无其他非零业务金额时，拒绝生成零值结论，Word 保留黄色 `XXX`。
- `run_project` 新增 `normalized_evidence.json`，组合流水线直接继承表格字段的来源文件、工作表和单元格，不再从旧审计表反推为 `unknown`。
- 生成问题清单升级为“检查总览＋问题明细”，按 Word 页码和优先级排序，增加检查位置、处理建议、优先级颜色、筛选、冻结窗格和打印设置。
- 历史利润表支持“净利润（净亏损以‘-’号填列）”等会计报表后缀，避免已存在的净利润被误判为缺失。
- 阿里云表格单元格契约补充跨行/跨列信息并完整往返 OCR XLSX；语义取数改为同时校验页内标题、科目行和列头，同页多表不再仅凭页内关键词误选。
- 电子设备只接受明确的“电子设备”列；“电力设备”“杂项设备”不再作为同义列，无明确来源时保留为空并进入问题清单。

## 0.7.2 — 2026-07-27

- 默认百炼模型切换为 `qwen3.7-max-2026-05-17`；黄色叙述和三类审核继续支持按任务单独覆盖模型。
- 历史报表改为先识别期间列再按科目取数，排除增长率和预测列，支持基准日审定数及同期间“资产－负债”派生所有者权益；金额不会再被误作期间表头。
- 同一历史报表存在于多个上传工作簿时，按已填单元格数和明确年度优先级选择更完整版本；期间一致时只补齐空值并合并证据，不再由先读取的不完整表阻断后续结果。
- 电子设备支持“固定资产—电子设备/电子设备净额”汇总行、两级原值/净值表头及明细表汇总，结果保留账面净值单元格和有效明细数量；歧义列继续保留 `XXX` 并记录原因。
- 新增参考 Word 叙述证据检索：按公司、行业、产品、业务模式、客户供应商、SWOT 和可比公司关键词给段落及表格行打分，不依赖文件名或固定段落坐标。
- 百炼叙述升级为 `yellow_narratives.v2` / `yellow_narratives_output.v2`；针对 `qwen3.7-flash` 使用 JSON Object 并在本地执行七字段白名单、结构和证据编号校验。
- 七个叙述字段改为独立小节点，每个节点最多读取 12 条相关证据；有证据时生成，无证据（如本次可比公司）时保持空白，禁止跨项目兜底。
- `workbook_semantics.v2` 增加收益法/市场法语义分类，避免同一评估值同时写入两个方法字段。
- 最终评估值、增减值和增值率根据用户最终选择的收益法、市场法或资产基础法动态取值，不再固定读取通富的收益法字段。
- 历史资产负债表和利润表自动按“科目列 32%、金额列均分”调整列宽，修复第 9 页长金额被拆成两行。
- 使用亦盛、夏弗纳、浙江晶引、铁投能源四组真实工作簿重新生成 Word；核心金额分别命中，所有问题项均取得生成后实际页码。
- 端到端运行目录新增 `normalized_evidence.json`，并纳入运行清单，逐字段保留来源文件、工作表和单元格范围。
- 四组真实资料的结构化表格占位符由 83/268 降至 68/268：历史报表由 75/204 降至 64/204，长期资产由 5/12 降至 1/12；12 个核心评估金额保持一致。

## 0.7.1 — 2026-07-27

- 新增 `workbook_semantics.v1` 通用 Excel 语义定位：不依赖上传文件名或固定单元格，按工作表特征、科目标签和列标题识别资产基础法、收益法、市场法的核心金额。
- 自动识别人民币元/万元、`账面/帐面`、`净资产/所有者权益`、`评估值/评估价值` 等版式差异；固定坐标仍作为已验证项目的高精度优先规则。
- 资产负债汇总、历史资产负债表、历史利润表和主要长期资产表支持语义回退；无法唯一匹配的单元格继续保留黄色 `XXX`，不猜测金额。
- 使用亦盛、夏弗纳、浙江晶引和铁投能源四组真实版式做跨项目回归，并增加 9 个脱敏正常/边界样例。

## 0.7.0 — 2026-07-27

- 新增 `生成问题清单.xlsx` 和 `生成问题清单.json`，逐项记录 Word 页码、位置编号、上下文、应取来源和处理建议。
- 前后端支持任意材料组合及 `.xlsx/.xlsm` 工作簿；只需一份材料或一项人工输入即可提交。
- 存在黄色占位符时不生成最终候选版，模板、映射和工作流契约错误仍保持硬失败。
